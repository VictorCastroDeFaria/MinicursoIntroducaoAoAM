# Minicurso Introdução ao Aprendizado de Máquina

Este repositório é uma reprodução do minicurso "Introdução ao Aprendizado de Máquina" ministrado no dia 22 de Novembro de 2022, durante a VII Semana Acadêmica de Engenharia Mecânica da Universidade Federal de Viçosa (SAEM - UFV). A carga horária deste minicurso foi de 3 horas, e o repositório disponibiliza os códigos usados e os slides para apresentação dos conceitos.
